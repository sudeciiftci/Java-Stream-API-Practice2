Java Stream API Practice

This repository contains Java practice projects focused on Stream API, parallel processing, and data operations.

Projects

1. ParallelStreamExample

Demonstrates the difference between sequential and parallel streams.

Topics covered:

* stream()
* parallelStream()
* forEach()
* Method references
* Sequential and parallel processing

2. FilteredStudentScores

A program that filters student scores and updates passing grades.

Features:

* Filter passing scores (50 and above)
* Increase passing scores by 5
* Collect results into a new list

Topics covered:

* filter()
* map()
* collect()
* Collectors.toList()

3. ShoppingCartCalculator

A shopping cart program that performs calculations on product prices.

Features:

* Calculate total price
* Multiply all prices
* Calculate the total of prices above 200

Topics covered:

* reduce()
* filter()
* Lambda expressions
* Stream API

4. ProductPriceAnalyzer

A program that analyzes product prices.

Features:

* Find the cheapest product
* Find the most expensive product
* Find the most expensive product above 200

Topics covered:

* min()
* max()
* Comparator.naturalOrder()
* orElse()
* filter()

Technologies

* Java
* Stream API
* Lambda Expressions
* Collections Framework
